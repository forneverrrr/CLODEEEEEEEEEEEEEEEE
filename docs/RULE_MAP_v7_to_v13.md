уничтожены, но **содержание перенесено полностью** — правила выросли из реальных
ошибок в семи отчётах, и терять их нельзя. Эта таблица доказывает, что ни один
пункт не выпал: каждое старое правило имеет новый ID в `references/rules.md`.

+ принципы §0 SKILL.md — **все имеют адрес в v13**.

## Что изменилось по существу, а не по форме

Перенос не был механическим. Пять правил изменили содержание — все в сторону
строгости:

1. **`EV-4` получил исключение.** Старое «не сдавайся раньше двух попыток»
   конфликтовало с запретом соседского прокси для участковых данных: одно правило
   толкало копать дальше, другое требовало честно сказать «нет данных». Теперь
   исключение прописано явно.
2. **`EV-5` больше не содержит «Believe surprising-but-sourced results».** Эта
   формулировка из core-kernel §4 была отменена ещё в v7, но сам файл никто не
   правил — теперь она заменена на `EV-6` (удивление повышает планку проверки).
3. **`MONEY-1` окончательно заменил правило «<3 компов = Low».** В core-kernel §7
   оно оставалось в старом виде и противоречило v7.
4. **`MONEY-7` дополнен правилом перераспределения веса N/A-категории** — раньше
   общий балл молча считался от неполной базы.
5. **`DOC-1` поглотил определение режима.** Режим A/B/C больше не определяется
   «что прислали», а выводится из инвентаря со статусами.
