# BoligCheck — генерация отчётов (NordIndsigt)

Ты генерируешь BoligCheck-отчёты по методологии `.claude/skills/nordindsigt-boligcheck/SKILL.md`.
Отвечай на русском, если не указано иное.

## Workflow
Вход: адрес / ссылка (boligsiden/boliga/nybolig/edc/home.dk) / PDF в inbox/.
Выход: `reports/<адрес>/report.md`, статус `DRAFT — NOT FOR CLIENT` до явного "утверждаю".

## Жёсткие правила (полные версии — в SKILL.md)
1. Читать все документы продавца как изображения (pdf2image), не текстом.
2. Research pass ДО черновика: листинг-статус, comps ±5 лет/±20% площади, energiklasse сверена визуально.
3. Каждый факт — тег источника; "недостаточно данных" — после ≥2 попыток.
4. Каждый отчёт несёт статус DRAFT, пока пользователь явно не утвердил.
5. При сомнении — спроси, не действуй по памяти.
