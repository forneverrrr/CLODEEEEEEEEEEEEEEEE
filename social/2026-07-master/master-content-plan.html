Раздел 0

Как читать этот файл

Один файл заменяет два прошлых (case-package + reels-library) плюс добавляет календарь и пояснения. Порядок работы — сверху вниз.

Логика документа:
1. Календарь (раздел 1) — что и когда публиковать. Это твоя рабочая шпаргалка: смотришь дату → видишь, какой пост/рил идёт → прыгаешь к нему по номеру.
2. Инструменты (раздел 2) — каким набором Flow-инструментов и в каком порядке делать картинки и видео. Одинаково для любого поста/рила.
3. Посты 1-8 (раздел 3) — карусели. У каждого: текст для IG, текст для FB, карточки (у каждой карточки — датский текст, который кладёшь поверх, промпт для картинки, и пояснение на русском что должно получиться).
4. Рилы 1-15 (раздел 4) — видео. У каждого: пояснение зачем, стилл-промпты (без текста), промпты анимации, тайминг субтитров.
5. Дальше (раздел 5) — идеи для следующих партий контента.
6. Что искать (раздел 6) — короткое ТЗ для чата-поиска домов: какие объекты нам нужны, чтобы закрыть недостающие углы.
Главное правило по всему контенту (не меняется): текст на картинках и в видео НЕ генерим внутри Nano Banana / Veo — генератор ломает датские буквы. Картинки/видео делаем чистыми (без текста), а датский текст кладём отдельным слоем сверху (Canva / CapCut / Type Overlays). Все кейсы анонимизированы: без адресов, суммы округлены, цифры-примеры иллюстративны. Перед загрузкой в Meta — скриншот или прогон через exiftool (снимаем AI-метку). Публикация — всегда вручную, без автопостинга.

Раздел 2

Инструменты и порядок работы

Одинаковый конвейер для картинок (посты) и для видео (рилы). Инструменты — из твоего набора избранного в Google Flow. Порядок строго сверху вниз.

Этап 0 — один раз на всю кампанию. Style Writer: грузишь moodboard (палитра navy/cream/rust/gold, 2-3 примера датской архитектуры новый+старый, документ/чертёж, интерьер с мягким светом, скриншот шрифта Geist) → получаешь текстовый style-prompt → сохраняешь как NORDINDSIGT MASTER STYLE. Дальше вставляешь этот кусок в начало каждого промпта — это держит все картинки в одном стиле.
1
Grid Architect на каждый новый пост

MASTER STYLE + краткое описание сцены → сетка 9-12 вариантов композиции → выбираешь и извлекаешь один лучший. Это черновой этап на дешёвой модели (Nano Banana 2 Lite), тут выбираешь композицию, а не финал.

2
Извлечённый вариант = анкер

Первая карточка поста (обычно обложка) становится reference-image для остальных карточек — держит единый свет и стиль.

3
Shot Explorer вариации ракурса

Грузишь анкер, просишь другой ракурс/приближение («medium close-up on the door») → получаешь карточки-детали, не переписывая промпт вручную. Инструмент сам меняет ракурс, держа свет анкера.

4
Mask Magic по необходимости

Точечно убрать случайный номер дома / уличный знак / лишнего человека / нечитаемый фейковый текст на документе — не перегенерируя всю сцену. Это же наша страховка анонимизации.

5
Image Editor финальный формат

Приводишь к 4:5 (лента) или 9:16 (сторис/рил). Расширяешь поле снизу под будущий текст. Длинный датский текст сюда НЕ вставляем.

6
Canva / Figma текст поверх

Кладёшь датский текст карточки (из блоков «Текст на карточке» ниже) поверх чистой картинки. Шрифт Geist, кремовый цвет, мягкая тёмная подложка снизу — без белого прямоугольника.

7
Mockup только CTA-слайды

Для продуктовых/финальных слайдов: анонимизированный фрагмент реального отчёта на планшете/столе. Не выдуманный документ.

Для рилов — те же шаги 1-5, потом видео-ветка:
8. Анимация: берёшь чистый стилл (без текста) и анимируешь в Veo/Flow промптом движения камеры (~8 сек — это лимит одной генерации). Никакого текста в промпте.
9. Stringout Creator: склеиваешь 2-3 клипа в один рил (15-24 сек).
10. Transition Machine: 1-2 плавных перехода на стыках (не на каждом — иначе выглядит как демо нейросети).
11. Type Overlays: кладёшь субтитры по таймингу из таблицы каждого рила. Текст — отдельным слоем, не в генерации.
12. Video Resizer: финально приводишь к 9:16.
Whisk — вспомогательный, на самом раннем этапе, если Grid Architect не дал нужного направления: подаёшь 2-3 референса настроения (только не реальные фото домов из объявлений — риск деанонимизации), получаешь альтернативу.

Раздел 5

Идеи для следующих нарезок

Углы, которых ещё НЕТ в контенте — под них специально ищем новые дома (см. раздел 6). Когда придут доки, из каждого делаем пост + рил тем же конвейером.

Tvangsauktion — «купить дом с молотка»

Целый неразобранный угол: покупка на принудительном аукционе = как есть, без ejerskifteforsikring, обычно один осмотр. Уже нашли 2 кандидата (Orte Vejsmark, Enghavevej). Сильная тема — мало кто понимает механику.

нужен: дом на tvangsauktion с доступным salgsopstilling

Асбест — живой кейс к существующей статье

На сайте уже есть статья про асбестовые крыши, но нет живого кейса. Эстернит до конца 80-х, запрет мойки под давлением, «trænger til maling» = шестизначная сумма.

нужен: villa/rækkehus с eternittag до ~1988

Радон выше нормы

Отдельная история — коммуна класса 2-3 по радону, что это значит и что делать. Ещё не разобрана как самостоятельный угол.

нужен: дом в коммуне с высоким классом радона

Расхождение цены между порталами

«Одна и та же квартира, разные цифры на разных сайтах» (кандидат Alskovvej). Наглядно про то, что цифрам из объявления нельзя верить слепо.

нужен: объект с разной ценой на nybolig vs boliga/boligsiden

Редкий тип владения — villalejlighed

Гибридный тип (кандидат Sixtusvej), который нельзя путать с обычной ejerlejlighed/andelsbolig. Образовательный угол про типы собственности.

нужен: villalejlighed или другой нестандартный тип

Гео-баланс: Копенгаген / Зеландия

Сейчас сильный перекос на Ютландию/Фюн. Нужны кейсы со Зеландии, чтобы контент не читался как «местная реклама одного региона» и работал для столичных FB-групп.

нужен: любой из углов выше, но объект на Зеландии

Долгий liggetid — «почему не покупают?»

Объект стоит на рынке 300+ дней. Что скрыто, если никто не берёт по этой цене — сильный детективный крючок.

нужен: объект с очень длинным сроком экспозиции
Раздел 6

Что искать в чате-поиске домов

Короткое ТЗ для отдельного чата (полный бриф — в репозитории research/brief-poisk-kandidatov.md). Цель — найти дома, которые закроют углы из раздела 5, не дублируя уже разобранное.

Приоритет поиска (что реально нужно новым партиям):

1. Tvangsauktion с доступным описанием — boliga.dk/tvangsauktioner, itvang.dk
2. Асбестовая крыша (eternittag до 1988) — поиск "eternit", "asbest" + villa
3. Зеландия / Копенгаген — любой сильный угол, но гео-баланс (сейчас перекос на Ютландию)
4. Andelsbolig с явным контрастом цена/boligafgift — boliga.dk/boliger/andelsboliger
5. Долгий liggetid (300+ дней) — сортировка по сроку экспозиции
6. Расхождение цены между порталами на один адрес

НЕ дублировать (уже разобрано): fælleslån, энергометка на блок, нет отчётов, цена vs vurdering, bevaringsværdig, старые фото, skunke, grundejerforening, byggeskadeforsikring, andelsbolig-база, масляный бак, сервитут, частная вода, separatkloakering, BBR-отставание, «??» в документе, чистый профиль. Новые находки этих углов брать только если исход ДРУГОЙ (например fælleslån выгодный, а не проблема).
