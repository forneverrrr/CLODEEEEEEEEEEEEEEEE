**MCP-сервер** — `.mcp.json` в корне репозитория:
```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```
Это официальный Playwright MCP (Microsoft) — даёт реальный браузер: `navigate`,
`screenshot`, `click`, `snapshot` и т.д. Подхватится автоматически при старте
новой сессии в этом репозитории, ничего переустанавливать не надо.

**Важный урок этой сессии:** первая попытка установить скиллы была сделана в
`/root/.claude/skills/` (домашняя папка контейнера) — и эта папка **откатилась
сама по себе** посреди сессии (контейнер эфемерный, может сбрасываться). Поэтому
всё выше продублировано именно в git-репозиторий — единственное действительно
надёжное место в этой среде.
