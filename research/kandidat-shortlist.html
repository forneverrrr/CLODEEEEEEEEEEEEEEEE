Прошёлся по датским порталам через веб-поиск по разным углам (масляные баки, tvangsauktion, andelsbolig, редкие типы владения, наследие, расхождение цен). Ниже — объекты, которые всплыли с конкретной зацепкой, каждый с источником и уровнем проверки.

Честно про инструмент: живой браузер (Playwright) в этой сессии не поднялся — MCP-сервер запущен на старом конфиге, я поправил путь к Chromium (chromium-1194), но подхватится только в новой сессии. Поэтому «пролистать» сотни объявлений визуально не мог — работал через веб-поиск по конкретным зацепкам. Отдельные URL объявлений часто отдают 404 (истекли) или блокируются (403) — это нормально для этих порталов. Поэтому детали ниже — из сниппетов поиска, их нужно подтвердить, открыв само объявление и вытянув PDF (salgsopstilling / tilstandsrapport / energimærke) — это и есть твой следующий шаг, из которого мы делаем отчёт. Список честный: не добивал его выдуманными адресами до 15 — вместо этого дал рецепт, как добрать остальные за минуты.

Рецепт: как добрать до 15+ за минуты

Живые фильтры-страницы порталов, которые сами дают поток «интересных» объектов — открой, отсортируй, забери адреса.

  1. Все свежие снижения цены за 24 часа — сильные снижения = мотивированный продавец, часто = интересный документ. boliga.dk/nye-prisfald
  2. Все tvangsauktioner (принудительные аукционы) — целый угол «купить как есть, без страховки». boliga.dk/tvangsauktioner · boligsiden.dk/tvangsauktioner · itvang.dk
  3. Долгий liggetid (стоит на рынке 300+ дней) — сортируй по времени экспозиции, длинный срок = «почему не покупают?». boliga.dk/resultat/villaer-til-salg → сортировка по liggetid
  4. Andelsbolig-листинги — под нашу новую тему: boliga.dk/boliger/andelsboliger — ищи низкую цену + высокую boligafgift
  5. Все новые объявления за 24 часа — свежак, пока не разобран: boliga.dk/nye-boliger
  6. Поиск по ключам в описании (в WebSearch/на портале): "olietank" "afblændet", "privat vandforsyning", "under udarbejdelse" (отчёты ещё не готовы), "bevaringsværdig", "separatkloakering" — это прямые триггеры наших контент-углов.
Следующий шаг по каждому кандидату: открой объявление → скачай PDF (salgsopstilling + tilstandsrapport + elinstallationsrapport + energimærke + для andel — nøgleoplysningsskema/regnskab) → пришли мне, прогоняю через nordindsigt-boligcheck → анонимизированный разбор → карусель/рил/статья Viden. Приоритет на разбор: №1 (бак), №4-5 (аукционы), №7 (andel), №9 (расхождение цен) — они дают самые новые углы, которых ещё нет в контенте.
