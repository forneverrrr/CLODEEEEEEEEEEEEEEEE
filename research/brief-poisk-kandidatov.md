# NordIndsigt — бриф для чата "поиск кандидатов на разбор"

Дата: 22 июля 2026. Этот файл — точка входа для отдельного чата, единственная
задача которого: искать реальные датские объявления о недвижимости, которые
дадут хороший образовательный контент (посты/рилсы/статьи Viden) после того,
как мы вытянем из них документы.

**Не путать с чатом кампании** — там весь маркетинг/сайт/промпты. Здесь только
поиск и первичная оценка кандидатов, до вытягивания PDF.

---

## 1. Контекст: что такое NordIndsigt и зачем это

Независимая датская служба проверки документов при покупке жилья. Публикуем
анонимизированные "testanalyse" (тестовые разборы реальных объявлений) как
образовательный контент — посты, рилсы, статьи на сайте. Все разборы идут
через скилл `nordindsigt-boligcheck` уже в основном чате.

**Твоя задача здесь — только этап 1: найти и оценить кандидатов.** Вытягивание
документов, анонимизация и написание контента происходит в другом чате.

## 2. Технические ограничения (проверено 21-22.07.2026)

- **Playwright MCP** сконфигурирован в `.mcp.json` корня репозитория. Путь к
  Chromium исправлен на `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` —
  если это новая сессия, живой браузер должен заработать. Проверь одним
  `browser_navigate` на простой сайт перед тем, как полагаться на него.
- **WebFetch по конкретным URL объявлений ненадёжен**: boligsiden.dk и
  dingeo.dk стабильно блокируют (403), у EDC/nybolig/home.dk отдельные
  страницы объявлений часто уже 404 (объявление истекло/продано) даже через
  несколько часов после того, как их нашёл поиск.
- **WebSearch — рабочая лошадка.** Даёт реальные адреса с конкретными
  деталями в сниппетах (цена, м², находки типа "olietank", "tvangsauktion").
  Это основной инструмент, не борись с WebFetch по каждому URL.
- Если живой браузер в этой сессии всё же работает — используй его для
  систематического скролла по фильтрам порталов (раздел 5 ниже), это
  надёжнее одиночных WebSearch-запросов.

## 3. Критерии отбора объекта (жёсткий чек-лист)

Объект достоин передачи в основной чат, если:
1. Есть хотя бы salgsopstilling — в идеале ещё tilstandsrapport,
   elinstallationsrapport, energimærke (или nøgleoplysningsskema/regnskab для
   andelsbolig/ejerlejlighed).
2. Объявление **активно на момент проверки** (не архив) — или это
   tvangsauktion с назначенной датой.
3. **Не дублирует уже разобранные кейсы** — см. раздел 4, что уже покрыто.
4. Есть хотя бы один конкретный, проверяемый сигнал в самом
   объявлении/сниппете — не просто "дом продаётся", а что-то вроде: находка в
   тексте, расхождение цены с оценкой, необычный тип владения, аукцион,
   долгий/короткий срок экспозиции.

## 5. Где искать — живые фильтры (открывать напрямую, не гуглить)

  `boliga.dk/resultat/villaer-til-salg` и аналоги для ejerlejlighed/andelsbolig

**Поиск по ключевым фразам** (через WebSearch с `allowed_domains` на
boliga.dk/boligsiden.dk/nybolig.dk/edc.dk/home.dk/danbolig.dk):
- `"olietank" "afblændet"` — масляный бак
- `"privat vandforsyning"` — частная вода
- `"under udarbejdelse"` — отчёты ещё не готовы
- `"bevaringsværdig"` — охраняемое здание

- `"tvangsauktion"` + город/тип
- `"andelsbolig" "boligafgift"` — andelsbolig-кейсы
- `"asbest"` + villa — под существующую статью сайта
- `"radon"` — отдельный угол, ещё не разобран

## 6. Гео и тип — держать разброс

Целевое распределение на партию из ~10-15: не более 40% из одного региона,
не более 50% одного типа жилья (villa/ejerlejlighed/andelsbolig/rækkehus).
На сегодня сильный перекос на Ютландию/Фюн — специально ищи Зеландию/Копенгаген.

## 7. Формат вывода этого чата

Для каждого кандидата, прошедшего чек-лист (раздел 3):

```
## [Адрес], [почтовый индекс город]

- Цена: [кр.]
- Сигнал: [конкретная находка/зацепка из объявления или сниппета]
- Уровень проверки: 🟢 (2+ источника/подтверждено) или 🟡 (1 сниппет, нужна проверка)
- Источник: [ссылка]
```

Не добивай список до заданного числа выдуманными строками — если нашёл
меньше, так и скажи, с честной причиной (см. как это было сделано в
`research/kandidat-shortlist.html` в этом репозитории — используй как образец
формата и уровня честности).
