# Справочные ссылки (не скиллы, не MCP — просто списки для просмотра)

Эти репозитории — не программы и не скиллы, а курируемые списки ссылок.
"Установить" их нельзя (нечего класть в `.agents/skills/`), поэтому просто
держим ссылки тут, чтобы не искать заново, когда понадобится конкретная
задача по сайту nordindsigt.dk.

| Ссылка | Когда открывать |
|---|---|
| [ripienaar/free-for-dev](https://github.com/ripienaar/free-for-dev) | Выбор бесплатного хостинга/CDN/DNS/аналитики для реального сайта |
| [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) | Поиск конкретного MCP-сервера под задачу (деплой, БД, аналитика) |
| [public-apis/public-apis](https://github.com/public-apis/public-apis) | Поиск бесплатного API (карты, геокодинг, погода) под функциональность сайта |
| [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) | Официальный маркетплейс — `/plugin install <name>@claude-plugins-official`, когда нужен конкретный плагин |
| [sindresorhus/awesome](https://github.com/sindresorhus/awesome) | Мета-каталог всех остальных awesome-списков |
